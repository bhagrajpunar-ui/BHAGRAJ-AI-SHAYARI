# BHAGRAJ AI SHAYARI

A Hindi Shayari and Status Progressive Web App (PWA) with a black-and-gold responsive interface.

## Features
- Hindi shayari collection: Attitude, Sad, Love, Motivation and Life
- Generate a random shayari from the built-in collection
- Optional topic text, copy, share and favorites
- Installable PWA manifest and service worker offline caching

## Run locally
Serve this folder from a local web server. Service workers and PWA installation require HTTPS or localhost.

## Publish with GitHub Pages
1. Push all files in this folder to the repository root.
2. Open repository **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch `main`, folder `/ (root)`, then Save.
5. Wait for the published Pages URL to appear.

## Important
The first version uses a bundled shayari collection. It does not call an AI model and does not currently earn advertising revenue. To add real AI generation, use a secure backend; never put private API keys in browser JavaScript. Ad monetization requires an eligible ad network account and policy-compliant implementation.
